# DeliveryOrderApp

Веб-приложение для управления заказами на доставку.

## Описание

Приложение позволяет создавать заказы на доставку, просматривать список всех заказов и детали конкретного заказа.

## Технологии

- ASP.NET Core 9.0 (MVC)
- Entity Framework Core 9.0
- SQLite
- Razor Pages
- Bootstrap 5

## Как запустить

## Требования

- .NET 9.0 SDK
- Entity Framework Core Tools
- Docker
- Docker Compose

## Инструкция

**Инструкция:**

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DuwangKing/DeliveryOrderApp.git
   cd DeliveryOrderApp
   ```
2. Запустите контейнер:
   ```bash
   docker compose up -d
   ```
3. Откройте в браузере: http://localhost:5000/Orders
